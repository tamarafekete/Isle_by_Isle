# Credits and asset licenses

Log every third-party asset the moment you add it to the project. Reconstructing this later is much harder.

## How to use this file

1. Add a row when you import any model, texture, sound, music track, font or script.
2. Copy the license name exactly as the source states it (for example CC0, CC-BY 4.0).
3. If the license requires attribution (CC-BY and similar), fill in the attribution text and show it in the game's credits screen.
4. Save a link to the source page, so the license can be re-checked later.
